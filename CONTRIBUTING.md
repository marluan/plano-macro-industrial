# Como contribuir

Obrigado pelo interesse em melhorar a proposta. Qualquer pessoa pode contribuir.

## Pull requests

1. Faça um fork do repositório.
2. Crie uma branch com um nome que descreva a mudança, por exemplo `atualiza-selic-dez-2026`.
3. Edite `index.html` e/ou `detalhes.html`.
4. Abra um pull request para a branch `main`.

No pull request, explique:

- o que mudou;
- por que mudou;
- quais fontes sustentam a mudança.

## Regras para o conteúdo

- **Todo número precisa de fonte.** Inclua link e data de referência na lista de referências do whitepaper (`detalhes.html#referencias`).
- **Mantenha as duas páginas coerentes.** Se um número muda no whitepaper, ele também precisa mudar na página de apresentação.
- **Prefira fontes primárias:** Tesouro Nacional, Banco Central, Receita Federal, legislação no Planalto e estudos acadêmicos.
- **Separe a compensação fiscal do impacto econômico.** Crescimento do PIB e economia de juros não contam como compensação pela Lei de Responsabilidade Fiscal.
- **Não remova os créditos nem o aviso de licença.** O conteúdo é CC BY 4.0.

## Sugestões sem editar

Abra uma [issue](https://github.com/marluan/plano-macro-industrial/issues) descrevendo o problema ou a ideia.
